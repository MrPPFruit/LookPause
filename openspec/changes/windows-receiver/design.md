## Context

本机为 Windows 10 22H2 x64/.NET SDK 10.0.302。此前只有 ICO，无 Windows 代码。GSMTC 的当前会话不证明前台归属。

## Goals / Non-Goals

先实现并证明唯一前台媒体安全控制。复用已有规则及现有手机包；不增加网站名单、浏览器扩展、网页脚本、通用远程输入或控制面板。不修改 Android 签名或 Mac 活动 change。

## Decisions

0.1.5回退核验：固定键使用既有已验证scope的KeyboardSurface候选，需可聚焦／可见，原1500ms采样预算内等待exact焦点条件；ack后重新读取同目标Playing、时间线及相同承载面，最后一次Left。无能力跳过，不降级到播放按钮或seek，不发键后立即恢复焦点。真实网站三轮及随后Space／左右键通过；任意focusable Group不因此自动具有媒体语义，其他样本仍需独立验证。轮询只等待条件，不是固定延时后盲发；UIA读前读后均核验撤销和预算。

0.1.4补充：Chromium原生时间轴的当前时间与总时长分置不同辅助功能属性，Windows通过同前台、同RuntimeId的标准COM只读FullDescription30159取得总时长，与唯一seek的ValuePattern组合解析；来源独立参与原有资格核验，不接收无单位数值。非Offscreen启用音量Slider收起后可能空bounds，仅将它作为同组结构证据，组、播放和进度仍需可见非空。真实样片已有一次连续3轮，但控制栏隐藏后缺少控件、暂停后描述变化仍导致撤销，未增加定时等待或漂移容忍；详见原生描述报告。

2026-10-21 用户批准取消固定容器名称硬门槛。保留原有明确媒体语义区域作为证据路径；新增无名组的结构路径：唯一明确可调用播放按钮、唯一 seek、唯一音量滑块及媒体动作必须形成封闭控件组，前三者直接属于同一 Group/Pane；可见后代不得混入普通正文、导航、其他控件或嵌套文档。此为有界平台能力规则，不声称能从任意辅助功能树证明实际 video 身份。不得以整页共同祖先或距离/面积阈值拼接。正常嵌套文档不因总数被拒绝；scope截止最近Document，时间只在相同最近Document中取，回退焦点比较从最近到外层的完整Document链。名称路径维持既有兼容范围，不承诺两路径覆盖完全相同的结构。

结构识别与暂停归属分层。实际 Chrome 原生视频的无名组已采到，但样本只有数值范围和局部已播放时间描述，缺少完整时间，不将无单位范围自行认定为秒。暂停后若仍无有效锚点，取消恢复资格；这一能力缺口不得用结构单测或Mac结果关闭。共用行为与合成验收用例存入仓库，Windows只提供Mac接续说明，不修改Mac源码或声称Mac已优化。

本机嵌套Chrome控件链发现同一顶层内子HWND的前台通知导致误撤销。经事件句柄、实际前台、GA_ROOT及事件／回调时刻取证，统一观察、执行、持有和回退的顶层身份；InputWatch仅在事件根、实际根、上次实际根均同一非零值时保留，否则撤销，之后以实际根更新基线。保持独立弹窗、切走再切回、未知及迟到冲突撤销，不按进程豁免、不忽略Invoke窗口期、不延时消抖。不是把最后回到原窗口当作未切窗。

2026-10-20 用户确认继续无扩展迁移，并采用 Mac 的接管规则：键盘、点击、滚轮（包括调音量）取消本轮恢复资格，但不停止观影；手动继续播放、再次离开后可重新建立一轮资格。明确播放状态直接进入单次暂停和结果确认，不再统一要求时间线先增长；未知状态不盲操作。媒体身份与暂停锚点分开，暂停结果确认仍须同目标 Paused、有效且未结束的时间线；持有及恢复前继续核验同格式/时长/位置。缺失时间线与已结束分开，缺失不能伪造数值，也不能获得自动恢复资格。

时间来源沿用 Mac 的选择：精确媒体区域内唯一明确时间文字优先，缺失时才读取唯一 seek 的明确时间描述；组合组与其子文字的相同语义去重，独立来源歧义拒绝，不接受无单位数值。seek 控件与可读时间来源分离，文字节点重绘不构成媒体身份，seek 身份变化仍撤销。完整时间文字不自动证明数值 slider 的单位，回退独立检查；恢复确认后先消费资格，再尝试一次回退。已有冻结 provider 的数据新鲜度问题仍须 Windows 真实状态转换验证，不能仅凭结构合法宣称可靠。

先最小只读 .NET 探针，枚举 GSMTC 与前台 HWND/UIA。只有可证明窗口、活动内容与具体媒体关联的路径才能执行；应用名或 GSMTC 当前会话不能单独授权。资格状态机串行化网络意图与观察，副作用前再次检查输入代次、上下文、结束和暂停锚点；未知禁止新动作。命令返回不授予资格，以实际状态确认。

2026-10-19 用户调整为先完成 Windows 功能迁移，由用户集中实测；真实媒体未通过项保持开放，不再阻塞 LAN/托盘实施。TLS/独立证书/DPAPI、严格帧和会话、一次允许配对，native DNS-SD 异步结果核对。托盘仅投影连接和方向。

协议核心用短锁串行化固定帧、配对回调和断线/超时，不在锁内等待 I/O 或 UI。每连接顺序读帧、有界写队列；TCP 接受即占用四个名额之一，握手有绝对截止。媒体仍为独立 worker，已认证 STOP/当前活动连接断线在入口撤销 epoch，不等待 UIA；旧连接关闭不得撤销新会话。UI 只异步投影状态和显示一次配对确认。持久身份原子保存 DPAPI 密文，损坏不静默重建；原生 DNS-SD 注册完成与实体手机发现分别报告。

## Risks / Trade-offs

UIA 可观察值重复的换片和最终观察到操作竞态仍须报告；无证据时降级，不以重复 PASS 消除边界。浏览器隐藏控件、系统权限、受保护视频可能不可读。不得为了赶进度先堆网络和测试框架。
