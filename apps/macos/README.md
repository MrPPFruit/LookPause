# Mac 接收端与媒体资格探针

普通产品入口：在仓库根执行 `bash apps/macos/build-app.sh`，打开本地 `.local/LookPause.app`。它是无Dock主窗口的菜单栏应用，被动接收手机连接，菜单提供状态、默认开启的登录启动和退出。首次配对在Mac点一次允许，系统辅助功能与输入监控授权仍由用户完成。普通进程权限须独立核验，不能用终端探针权限替代。

当前使用同一套通用AX媒体语义和恢复所有权机制，不按应用或站点白名单分支，不安装扩展或执行网页脚本。明确播放/暂停按钮、原生播放开关值、播放器暂停状态及同一窗口的实际进度可提供线索；静止和音频活动不证明暂停/播放。未知、多义目标、输入框焦点不盲发按键。

原生控件用AXPress，自绘模糊按钮在已核验播放状态/目标/焦点后使用固定Space。合格自动恢复后，只有非网页、明确秒单位且可写/数值范围有效的原生时间线才回退一次（初值5秒，截断到下界）。其他情况照常暂停/恢复并跳过回退；网页ARIA数值及AXDecrement成功返回不能保证实际seek，不把它当原生可写时间线，也不猜测Left含义。操作后观察实际状态与进度，不重试或再切换播放。用户接管、目标变化、停止或断线取消恢复资格；真实按键、点击、滚轮均算接管，纯鼠标移动除外。LAN没有按键、shell或任意脚本入口。

S25→YouTube普通入口已通过实际转头暂停/回看恢复及接管保护。B站、QuickTime与恢复回退的最新证据和范围见 `docs/comet/reports/2026-10-17-media-background-followup.md`。同页换片、隐藏/模糊控件、全语言和全播放器兼容仍有边界；资格入口成功不等于新版本S25整链已交付。

## 本机资格入口

执行 `bash apps/macos/build-probe.sh`，产物仅在 `.local/LookPauseMediaProbe.app`。`self-test`验证纯解析/协议规则；`generic-state`只读当前前台媒体；`receiver-test`强制只监听loopback、不发布Bonjour，测试凭据与普通手机凭据分离。它复用普通入口同一媒体裁决器，供固定观看意图验证真实播放器，不向产品增加测试按钮或配对后门。

历史`pilot-cycle`模拟单次离开/回看，等待20秒仅供人工核验，不是视觉阈值；专用QuickTime/Chrome探针只作历史对照。`input-watch-test`固定Shift系统事件用于监听诊断。不得用这些入口替代普通产品权限和三星真机结果。

构建脚本原子替换可执行文件，避免在运行进程映射的旧二进制上直接覆盖。原始媒体、截图、本机日志、密钥和配对凭据均不提交。
