# LookPause 现行产品范围

个人自用；Android 手机负责本地粗粒度观看方向识别，桌面负责真实媒体状态与执行裁决。手机主动选择并连接一台 Windows 或 Mac，桌面被动等待并显示连接状态。桌面自动识别当前前台媒体，不要求用户逐页授权、手动选择视频或手动绑定目标。首次配对、系统权限、校准、开始/停止观影仍需明确用户动作。

前台自动识别必须区分应用、窗口、浏览器活动页及具体播放项；不能确认唯一合格媒体时不操作。内部在暂停时记录目标身份、播放项版本与恢复资格；切换应用、窗口、标签页或媒体会撤销旧资格。取消的是用户手动绑定步骤，不是内部安全关联。空格键响应不证明播放状态或暂停归属；不得用盲目 TOGGLE 代替安全裁决。

Mac 为菜单栏后台应用，不显示 Dock 主窗口。日常菜单只提供连接/观影/媒体/异常状态、登录后启动开关和退出；手机负责主动连接及观影开始/停止。登录后启动默认开启，可在菜单关闭；开机启动指用户登录后启动，不是登录前系统服务。首次配对采用手机发起、Mac 点一次允许并记住设备；系统权限保持首次确认，不增加常驻设置、目标选择或播放器控制按钮。

核心规则：开始观影不主动播放；明确 PAUSE/PLAY，不用盲目 TOGGLE；仅已验证由本工具暂停、目标未变且资格有效时恢复。用户手动播放/暂停、媒体变化、结束、断线或切换电脑均清除恢复资格。无法可靠区分手动干预则降级禁用自动恢复。

视觉状态采用 ATTENDING/AWAY/NO_FACE/UNKNOWN 的原文概念；UNKNOWN 保持媒体状态，摄像头故障不等于无脸。图像仅本地内存处理，不上传、不默认留存。本次S25锁屏后断开，持续锁屏/息屏观影未通过；只动眼不转头及多播放器兼容仍待实测。

技术方向：Android Kotlin、Compose、CameraX、MediaPipe；Windows C#/.NET、WinForms 托盘、GSMTC；Mac Swift 菜单栏、Bonjour、针对真实播放器的适配器。更早 Python 方案已替换。

目标手机按用户提供为三星 S25 / Android 16 / One UI 8.5；Android 主开发机为 Mac。网页首先在用户 Chrome 的 B站、YouTube 验证，本地先验证 QuickTime；YouTube 已有 S25→Mac 普通入口暂停/恢复及接管保护真链。B站与QuickTime通用路径现有本机资格入口驱动的真实媒体证据，更新后的S25→Mac→YouTube普通入口已验证跳过回退仍暂停/恢复、初始手动暂停保持、STOP及重连不补播；B站/本地新版S25整链尚未复测，证据见 docs/comet/reports/2026-10-17-s25-web-retest.md。原始资料仅本地保留，原文阈值和性能指标是研发初值。协议命名与细节参见 protocol/CONTRACT.md。

网页控制当前优先验证无扩展路径：macOS 辅助功能读取前台媒体状态，必要时发送固定媒体按键；不要求 Chrome 开发者模式。只有已知真实状态与恢复资格时才允许键盘执行，不能将空格切换默认当作 PAUSE/PLAY。扩展安装方案暂缓，原型代码不代表已采用或已支持。

## 2026-10-16 已确认的轻量通用 Pilot

通用性与轻量优先；Chrome、QuickTime、B站和 YouTube 为样例，不定义产品支持名单。先用前台上下文、系统/辅助功能的现成播放线索和本轮操作记录形成体验闭环；音频只是候选信号，不预设技术路线，不堆评分系统或逐站脚本。完整精准判态不作为先体验门槛，信号不足不盲切换。固定本机 Pilot 与正式产品资格分层：前者只按实测范围报告，不能覆盖上文正式手动暂停保护合同。

当前实现使用前台媒体语义区域的通用 AX 控件；系统音频活动仅观测，实测暂停后可能仍激活，不单独触发控制。原型暂停后键盘/点击/滚轮接管即取消恢复（纯鼠标移动除外），保守规则可能漏恢复；完整媒体身份、结束和所有手动操作来源仍需后续验证。手机/菜单栏普通入口现已实现，S25→YouTube 最小闭环实测通过；尚不代表完整产品验收。

## 2026-10-17 用户确认的恢复补偿

仅在本工具自动暂停且仍拥有恢复资格、同一前台视频成功自动恢复后，按可核验能力额外回退一次，补偿离开判定期间漏看的内容。用户最新确认：能确认安全回退才回退，不能确认就跳过，不影响暂停和恢复，不逐个网站适配。当前只对非网页、明确秒单位且可写、数值/范围有效的原生时间线回退至多5秒；网页及其他能力不足的播放器照常暂停/恢复，跳过回退。不根据域名、应用名或未验证的左键含义猜测回退，不增加按钮/权限。已接管、目标改变、停止、断线及未知状态均不回退。重复观看意图不重复回退，命令提交和实际进度验证分开记录；失败不重试，不为了补偿再暂停或再播放。

本轮按用户决定先验证功能，长时间后台、锁屏/息屏及耗电DEFERRED；短时模拟器后台通过不代表三星稳定性已验证。
