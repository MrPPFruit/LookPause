# 显式快捷键兼容模式

## Why
部分自定义网页播放器未暴露现有UIA路径要求的播放按钮。2026-10-31用户明确接受未知状态可能误切换的取舍，要求独立模式，不再以播放控件识别作为执行前提。

## What Changes
- 默认关闭的托盘勾选项，仅在下一次手机START时生效。
- 不识别播放状态，按离开／回看各一次固定Space，不回退、不重试；显示效果未确认。
- 仍校验前台、文档、非编辑焦点、输入健康及修饰键；首次绑定后输入、切窗或焦点变化解除本次控制，需重新开始。
- 正常模式沿用现有安全资格；不自动降级。

## Capabilities
### New Capabilities
- `shortcut-mode`: 用户明确承担状态未知风险的固定快捷键模式。

## Impact
只改Windows实现、测试及中文共用说明。不改协议、Android或Mac源码，不增加扩展或网页脚本。无法识别同页自动换片、播放结束或按键未生效，不声称可靠媒体归属。
