## 背景与范围

项目尚无实现。本阶段仅证明前台媒体资格；不接 LAN、不实现菜单栏产品、不依赖手机。

## 实现决策

- [LPMAC-01] 使用 NSWorkspace 的前台应用身份；QuickTime 固定 Apple Events 获取前台文档。Chrome 路径优先无扩展的辅助功能状态读取＋固定按键，核对前台窗口活动页，禁止选择后台正在播放页；不能唯一判断即拒绝。
- [LPMAC-02] QuickTime 先验证 playing、rate、current time 与文档身份，再验证明确暂停/播放。网页读取实际 video 状态，操作仅允许固定 pause/play；不开放任意 JavaScript、按键或远程执行接口。
- [LPMAC-03] 操作前后核对身份，暂停时内部记忆播放项及上下文；非本次命令引起的状态变化撤销资格。若播放器无法提供可靠手动干预证据，保持自动恢复禁用，不用轮询频率伪造归属。

## 权限与技术选择

系统隐私授权不可替代为关闭保护。Chrome 全局允许 Apple Events JavaScript 会扩大访问范围，因此不自动开启。有限域名扩展原型已准备但用户质疑其必要性，当前 DEFERRED、未安装。先验证辅助功能提供的状态是否足以在明确 PAUSE/PLAY 语义下使用空格；无法证明则不操作，不能用工具 DOM 观测替代产品状态来源。

## 主要风险

QuickTime 的 pause 词典指向录制，电影暂停须实测；多个视频、前台切换竞态、网站自定义行为与播放器权限可能阻断。浏览器检查工具只作为独立观测，不计产品调用证据。

## 验证与回滚

先一个本地公开视频测试原生实际状态与操作，再在用户 Chrome 真实 B站/YouTube 页核验。输出脱敏报告；原始证据、媒体和构建留在 .local。实现留在独立分支，未合格不整合为已交付产品。

## 2026-10-16 轻量通用 Pilot 迭代

用户确认以通用性与轻量优先，测试应用不定义支持名单。LPMAC-01/02 使用前台应用及聚焦窗口上下文、通用 AX 媒体控件，不按站点注入脚本；Core Audio 输出活动仅作辅助，不采集音频。LPMAC-03 将本轮操作记录与本机键鼠输入监听、上下文/状态变化关联；原型仅对观察到真实暂停转变的上下文尝试一次恢复，按键/点击/滚轮即取消（纯鼠标移动除外）。不要求补齐所有播放器状态后才体验，不搭评分系统或大规模测试设施。未知、歧义、监听失败仍不盲切换。固定 Pilot 命令模拟一次离开/回看，非任意按键接口、无网络；不进入普通手机或菜单栏入口。短轮询只辅助观察，不能证明未观察到的所有操作或媒体身份，因此结果按 Pilot 实测范围报告，不能称通用安全保证。
