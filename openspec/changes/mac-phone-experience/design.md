## Context

复用已测试的通用 AX 媒体核心。当前只有固定循环；Android SDK36/JDK17 已有，S25 尚未连接。用户明确局域网直连、Mac 首次点一次允许，日常菜单不增加连接按钮。

## Goals / Non-Goals

目标是实际手机意图驱动媒体，而非扩大资格设施。非目标为全播放器兼容、Windows、云端图像或任意远程输入。

## Decisions

- [LPEXP-01] 同一 Swift 可执行目标提供普通菜单栏入口，AppKit NSStatusItem；SMAppService 登录启动。辅助功能不足显示状态，首次系统授权按 OS 流程。
- [LPEXP-02] 实验服务 _lookpause._tcp.，TLS 流式换行 JSON，最多 4096 字节/帧。Bonjour 提供证书指纹；首次按用户批准的 LAN 信任场景由 Mac 确认手机并签发随机凭据，后续凭据与证书固定。私钥/凭据入 Keychain/Android Keystore。首配属于 TOFU，不能宣称抵抗首配时主动中间人；正式远程/不可信网络不在本版本范围。固定本机 openssl 生成自签证书后删除临时私钥，TLS 协议由系统实现，不自造加密。
- [LPEXP-03] 持续意图裁决器串行拥有状态；暂停/恢复结果用定时观察，取消固定 20 秒回放。START 不播放，STOP/断线/超时清资格；会话与严格递增序号阻止旧事件。输入监听只在暂停所有权有效时启用；持有期间轻量核验上下文与控件，不反复枚举音频。
- [LPEXP-04] Kotlin/Compose 一页、NsdManager、系统 SSLSocket、CameraX + MediaPipe 本地粗粒度方向。开始后短暂基准，AWAY/NO_FACE/ATTENDING 去抖；UNKNOWN/相机错误不当作离开。前台摄像头服务从可见界面启动，退出/停止释放相机。无图像持久化或网络字段。
- [LPEXP-05] 先 Mac 固定意图真链、再模拟器界面、最后 S25 实际识别/控制；构建与模拟器结果不替代真机。

## Risks / Trade-offs

通用 AX 仍无法覆盖模糊/隐藏控件 → 返回未知，不误切换。页面内部换片/结束与平台竞态 → 仍有既有 GAP，不能宣称完整恢复保证。首配无扫码/输码 → 采用用户批准的 LAN TOFU，一次批准并固定后续身份。系统权限、未连接真机 → 保存可安装产物，必要时请求最少物理操作。

## Migration Plan

旧资格路线 SUPERSEDED，限制不写成 canonical 支持。唯一 integration 分支与阶段短分支整合；未通过 S25 验收不合 main。回滚停止接收端/手机服务并回到源码基线；不删除用户播放器资料。

## 2026-10-17 当前体验收尾

[LPEXP-01] 首次系统查询可能返回notFound（记录不存在），与notRegistered一并尝试登记；requiresApproval不重复覆盖系统用户选择。普通进程与后台任务系统日志交叉核验，菜单同时呈现辅助功能和输入监控缺失。

[LPEXP-03] 复用通用AX控件。原生播放开关的0/1值可判态；网页模糊按钮的播放器祖先可提供明确paused状态，playing缺失时仅以同上下文中实际进度前进补充。离开后最多短暂采样2秒；静止不产生暂停结论，结束/加载优先拒绝。原生AXPress与自绘按钮固定Space按能力选择，均在操作前重核目标与状态；键盘焦点或祖先为输入框则拒绝。InputWatch只豁免本进程、本轮随机标记的固定Space/Left，真实键鼠继续撤销资格。标题去除通知数和音频提示后加入上下文，换片标题变化亦撤销。

用户最新确认：回退为恢复成功后的可选补偿；能力不能确认就跳过，不影响暂停/恢复，无新按钮或逐站适配。实测网页ARIA时间线AX写入/Decrement成功不代表seek，Left含义也并非统一，因此移除这两类回退。当前唯一回退路径是非网页、可写且明确秒单位/数值范围有效的原生时间线减至多5秒；写入前保存实际秒数作为验证基准，不借用可能滞后的进度摘要。未取得能力或写入失败即清除已完成恢复的临时资格，不再操作播放；提交后只观察实际进度，不重试。保留现有固定Space暂停/恢复及输入框/焦点/前台/接管保护；不保留未使用的Left、通用键码和焦点开关参数。首次探索的媒体脚本候选仍撤回，无新自动化权限。

[LPEXP-04/05] 相机生命周期绑定前台服务，活动页退到后台不解绑相机或断开TLS；短时后台检查实际新帧时间与连接。用户已暂缓长时间、锁屏/息屏与耗电测试，相关项DEFERRED；手机系统版本及三星后台结论仍以真机证据为准。不预先申请忽略省电、唤醒锁或自启动权限。

[LPEXP-03] 进度样本必须关联同一进程、窗口和上下文，不能用另一同名窗口的进度作为正在播放证据。恢复/回退确认期间收到新的离开意图，确认恢复后继续处理该离开，不能因中间phase而丢失。每次副作用前重新检查用户接管与前台关联。

2026-10-18 [LPEXP-01] 用户确认PausePal英文显示名。只替换双端可见文案、Mac CFBundleName/DisplayName及Bonjour可见实例名；Android用app_name资源复用，versionCode/CFBundleVersion递增到2。安装ID、服务类型、证书/凭据、UserDefaults和安装目录/可执行名保留，避免扩张为协议迁移与重新配对。

2026-10-18 [LPEXP-03] 可观察归属收紧：进程/窗口/上下文加播放与seek控件身份、有效时长；暂停取得与持有期间绑定时间位置，恢复执行前再次核对，ended/loading/冲突覆盖Play标签。进度样本按同一媒体条件绑定。时间文字节点会正常重建，不将其ID当媒体版本；固定观察来源失效则撤销。缺失时间线不授予恢复资格。通用AX相同全部观察值不能证明播放项版本，保留P2 GAP，不声称完整身份合同闭合；详细真实证据与审查见2026-10-18-media-boundary-security报告。

2026-10-19 [LPEXP-03] 用户批准覆盖此前“网页一律跳过”的策略：只在同媒体自动恢复被实际确认后调用一次回退。原生可写秒时间线优先，无能力则尝试固定Left一组down/up；复用既有Space的焦点/输入框/修饰键/前台检查，固定键枚举仅Space/Left，无LAN键码字段。本进程随机轮次标记加pid只豁免这两个固定键，真实键鼠继续撤销。回退返回“已尝试”与可选前值，读不到进度不冒称成功；最多观察2秒，不重试、不通过暂停/播放纠正结果。AXSetValue已尝试但报错时不再补Left，防止双退。Left语义受应用决定是用户已接受的有界尝试风险，不扩大暂停/恢复所有权。

2026-10-19 [LPEXP-03] 用户现场已暂停→UNKNOWN→ATTENDING无法恢复，根因为receive(.unknown)无条件clearOwnership。现将方向确定性与暂停归属分开：.pausing继续原2秒结果确认，.paused继续既有InputWatch/前台/暂停锚点监测；UNKNOWN自身零播放/回退，只有后续ATTENDING才能恢复。其余phase沿用取消，避免已恢复后在未知中追加Left；不增加宽限TTL或新识别阈值。STOP/断线/超时/相机错误仍强撤销；Android相机故障原有UNKNOWN后STOP和帧看门狗不变。仅复用现有状态行显示冻结，未增控制。旧代码失败与新版多轮真链用项目内test_unknown_recovery.py重放，非S25替身。
