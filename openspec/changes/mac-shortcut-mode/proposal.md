# Mac 快捷键兼容模式

唯一目标 MAC-SHORTCUT-01：用户明确选择后，无法识别播放控件的前台播放器也能尝试固定Space。用户2026-10-31已明确确认与Windows一致的模式、交互及误切换风险；正常模式保持严格保护。父路线图为LPEXP-03的通用观影能力，本变更是独立、默认关闭的例外，不以前阶段验收完成为前提，不关闭父GAP。

入口：菜单“下次观影用快捷键兼容模式”，默认关闭、重启不记忆，只在手机START读取。开始零输入，离开／回看各一次Space，UNKNOWN零输入，无回退／重试。不判断播放状态，所以原本暂停、结束、同页换片可能误切换，由用户确认效果。键鼠／前台／焦点变化、观察失效、停止或断线解除本轮，须重新START。

完成条件分层：实现默认入口与明确状态、独立代码审查、必要编译／菜单截图；播放器及S25体验由用户自行反馈，不由代理回归。反例：编译通过但开关未接START，或在正常模式自动进入盲切换。无新权限、依赖、协议、手机改动、站点名单或通用远程输入。

Parent acceptance: independent。与现有LPEXP-03并列的显式例外，不把该活动父阶段作为已完成typed依赖。
