# 设计

独立ShortcutSession复用现有意图入口与InputWatch，不把未经验证的动作注入MediaSession。UI选择仅在START读取，当轮模式固定；重启默认普通模式。首次AWAY只读绑定顶层窗口、进程、文档链和exact焦点，不找媒体控件、不抢焦点。任何编辑祖先、修饰键、不完整观察或过期采样拒绝发键。

首次绑定后持续保留输入代次及边界；接管、观察失效或提交失败后整次disarm，仅新START可重置。回看前先消费一次性pending，重复意图与UNKNOWN不新增动作。固定Space执行前再次读取同边界及资格；部分提交仅清理释放，绝不补按。只豁免本进程随机标记的Space，保留原Left豁免。系统插入成功不视为媒体效果成功。

独立环境接口供测试模拟输入撤销、采样迟到与部分失败，测试不能触及用户媒体。菜单复用现有微软雅黑9号、系统菜单和勾选样式；通过真实WinForms离屏图检查，不将其算作系统托盘实测。实际网站控制及S25验收单独记录；没有真实运行观察面前不宣称该站已兼容。
