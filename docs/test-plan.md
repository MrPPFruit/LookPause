## 轻量通用 Pilot 的本轮证据

先检验同一代码跨应用可达，再扩大覆盖；不为样例增加应用/站点分支。Chrome/YouTube 与 Safari 本地视频均已观察到暂停→恢复；YouTube 手动播放再暂停通过可观察状态变化取消，初始暂停零命令；Safari 自动暂停后固定 Shift 系统事件触发 USER_INPUT，零恢复且保持暂停。输入监听仅记录撤销原因，不记录按键内容。

QuickTime 隐藏控制条和 B站模糊按钮在通用 Pilot 中为 UNKNOWN/零命令，不能称通过暂停/恢复。Core Audio 活动在 QuickTime 明确暂停后的 0.11～4.2 秒采样均为 true，否定它直接代表播放的前提，音频控制候选已撤回。上述为本机模拟视觉意图的技术真链，不是 S25 视觉链、普通产品交付或全应用兼容证明。T09/T12/T17 等不据此勾选。

## 2026-10-17 手机到 Mac 普通入口实测

S25 真实转头触发 AWAY，Mac 日志确认已自动暂停；回看 ATTENDING 后确认已恢复播放，用户反馈一致。随后自动暂停状态下的真实键鼠接管撤销资格，用户再离开/回看，YouTube 始终停在同一时间点；用户确认手机已停止识别。该保护场景为“自动暂停后手动接管形成无恢复所有权的暂停”，不能冒充初始用户手动暂停的完整覆盖。Mac 后续已记录“已停止观影”和断开，断线持有暂停资格场景及 S25 系统版本/后台/锁屏均未完整实测。详细命令、证据边界与剩余项见本日进度报告。
