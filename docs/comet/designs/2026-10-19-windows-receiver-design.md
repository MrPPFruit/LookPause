# Windows 实现决策

首个实现是只读 GSMTC/UIA 资格探针，验证系统可观察面，之后才选择执行接口。不把应用名、窗口标题或系统推荐会话当唯一媒体身份。UIA 可用时优先操作已观察的具体前台控件；不能证明绑定时不退化为全局媒体键。

归属裁决单 owner：记录窗口/活动文档/控件 runtime identity、媒体上下文与暂停位置。低层输入和前台变化递增撤销代次，副作用前重读，已暂停 UNKNOWN 继续监测。原生 API 最终竞态保留为边界。确认时间和精度在 Windows 现场确定。

后续网络只传固定意图，身份本机独立生成并以当前用户 DPAPI 保护。托盘不拥有媒体状态。高风险认证和输入边界有独立审查。实际入口与探针分开取证；相同可观察值换片不能靠更多测试声明解决。

Mac 路径的 canonical OpenSpec skill 在本机不存在，使用已安装 OpenSpec CLI 模板创建和验证 artifacts；不伪称执行不存在的 skill。Ponytail 未安装，以独立方案审查检查复杂度，不虚报已调用。

现场机制：浏览器连接创建的后台测试标签并未成为原生前台，必须用实际可见的新窗口验证。实际 Chrome 前台暴露唯一 Document、同一媒体容器的播放按钮与 Seek RangeValue，隐藏的精确定位条排除；执行选定控件 Invoke，不用全局 GSMTC。Windows Media Player 已真实解码样片，但仅提供无范围 ValuePattern，不能证明未结束，因此保持能力不足，不按已知样片长度补产品资格。

当前裁决使用 UIA 原生条件查询与属性缓存，读取 Button/Slider/Document，再有界核验祖先；最多500个相关控件、35层、总采样1500毫秒。完整性是返回后的拒绝条件，不能取消单次阻塞的UIA调用。必须有唯一可见播放按钮、明确媒体语义容器、同容器唯一定位条和唯一时间文本，并用时间文本独立核对RangeValue的秒单位、当前位置与总时长；不能把任意公共祖先或任意range当作媒体证据。Document名称/Value仅在内存做身份关联，不输出原文。原生播放器缺少稳定播放项身份时拒绝资格。

START不执行动作。Checking先观察同一目标的实际进度推进，再Invoke一次暂停；确认paused才持有归属。UNKNOWN只保留Pausing/Owned的原有监测和截止时间。Owned持续核验暂停锚点，恢复前重读，Resuming确认playing及进度推进；恢复中再次侧看需要重新走Checking。当前常速进度跳变检查并未证明任意倍速兼容。

独立UI消息线程监听键/点击/滚轮与前台变化，纯移动不撤销；媒体owner串行。STOP、断线、EOF、队列溢出在入口原子撤销，不等待阻塞采样；队列意图携带接收代次，避免迟到请求重新获得新代次。输入监听心跳超过1秒粘性失效，必须先发布失效再更新时间，避免短暂重新授予资格。句柄与心跳仍不能证明低层钩子从未被系统静默移除，是待原生验证的平台边界。

执行先读取控件和InvokePattern，最后核验语义、前台、输入代次、监听健康和采样年龄。已被系统接受的Invoke不能取消；同观察值换片及最终系统竞态仍保留。资格CLI仅接本机固定枚举，不新增产品菜单或远程输入接口。最新版真实多轮失败保持开放；用户随后调整为先完成迁移，再由用户集中实测，LAN/托盘不再等待桌面工具恢复。

迁移实现采用短锁协议owner与独立媒体worker；协议锁内只读不可变凭据快照、状态裁决、有界队列写入和传输取消，不等待磁盘/UIA/UI/网络。入口STOP/断线立即撤销；PendingIntent带观影代次，迟到媒体状态不跨轮次。网络任务明确脱离UI同步上下文，真实TLS断线回归不依赖UI消息泵。

DPAPI原子文件持久UUID/PFX/token；Schannel真实拒绝EphemeralKeySet，因此导入Windows当前用户临时密钥容器，不设PersistKeySet或Exportable，随证书释放。首次token先落盘为未确认，客户端有效认证事件后条件确认；ready丢失的未确认配对可经再次明确批准恢复，已确认凭据不能被无token覆盖。磁盘条件提交及确认均在协议锁外，按预期token防止迟到覆盖。

原生DNS-SD按异步回调管理注册/反注册；参数由GCHandle保持，退出只请求停止并有界等待，不对可能已释放的取消指针操作。注册成功仅说明系统接受公告，不声明手机发现。普通入口无主窗口、同用户单实例；HKCU登录启动默认开启并保存关闭偏好，首次配对为modeless原生窗口，默认拒绝；图标仅按认证与方向投影。

回退仅在自动恢复playing且进度推进后消费归属，再一次执行。原生可写秒时间线优先；网页仅明确播放器焦点下Left，所有UIA读取之后最终核验前台/输入/采样年龄再提交；只排除本进程随机标记的Left，部分插入仅清理释放，不重试按下。Checking补充进度诊断；当前UIA资格仍拒绝无稳定播放项的旧WMP，不宣称已解决本地兼容。
