# Windows 无名媒体控件组修正与跨端交接

本页记录0.1.3历史结果；后续0.1.4的原生时间描述修正、真实视频结果与仍开放问题见[后续报告](2026-10-21-windows-native-description.md)。

日期：2026-10-21。分支 `codex/windows-receiver`，起点 `ea7b7df`，开始时工作树干净。用户批准按研究方案实施，并要求 Mac 也评估共用问题。Windows 本轮没有修改 Mac、Android 源码或协议。

## 根因与范围

用户报告的“缺少明确的媒体语义区域”来自 UIA 对祖先 Group/Pane 名称及 HelpText 的固定词匹配。日志显示输入健康，代码到达该拒绝点前已通过唯一可调用播放按钮检查。浏览器只读观察确认样本使用原生视频；Windows 实际 UIA 采到无名 Group，直接属于 Document，其直接子控件包含暂停、视频时间进度条、音量、静音、全屏和更多媒体控件。该组未满足旧名称规则。

根因属于将平台的表现形式当作能力与身份合同。网页原生视频在 Windows 可映射为普通 Group，Mac 的 AX 角色描述不构成 Windows 必须出现相同名称的依据。参考 [HTML-AAM 的 video 映射](https://www.w3.org/TR/html-aam-1.0/#el-video)；真实平台样本与规范分别记录，不用规范代替运行结果。

## 已实施

- 保留既有明确媒体语义区域路径，并增加保守的无名局部控件组路径。唯一播放、唯一时间进度及唯一音量控件直接同组，至少一个明确媒体动作；可见后代出现其他控件、无关正文或文档即拒绝。不能从不同分支或整页共同祖先凑齐证据。
- 识别原生视频的时间进度标签，不把普通滑块、音量或含相似词的正文当成进度。
- 去掉“可见 Document 总数大于一即拒绝”的过宽判断；scope 搜索截止最近 Document，时间读取必须同最近 Document。目标身份加入文档链，回退焦点比较最近到外层的完整文档链，不能让兄弟框架借共同顶层取得资格。
- 本机嵌套控件验证还复现了前台误撤销：一次控件调用期间，前台事件及实际前台先指向 Chrome 子 HWND，再返回顶层 HWND，两者的 GA_ROOT 相同。原逻辑将原始句柄变化当作切窗。现统一观察、执行、持有及回退的顶层身份；只有事件根、实际根及上次实际根三者同一且非零时保留。真实不同顶层、独立弹窗、未知或迟到冲突事件仍撤销；不按进程豁免，不用 GA_ROOTOWNER 合并弹窗，不加延时消抖。最近两条固定数值诊断保留事件／实际根及时间，不记录窗口标题。
- 播放状态、暂停结果确认、有效时间锚点、接管及停止／断线撤销保持。未采用无单位 RangeValue 授予恢复资格。
- `--probe` 增加固定类别的组结构与产品读取结果。排查时曾临时打印目标组成员名称和局部值，已撤回临时代码；未将原始诊断、用户网站链接或截图加入公开文件。
- 版本为 0.1.3，发布到独立 `.local/windows-0.1.3`；旧运行进程及包未替换，配对文件保留。

## 尚未解决的原生时间能力

真实样本未暴露完整时间文本。进度滑块的 ValuePattern 只有局部已播放时间描述，另有数值 RangeValue；局部时间与数值位置不一致，其原因尚未定位，缓冲与读取新鲜度需区分，不能直接推定有效秒时间线。结构合格后若暂停确认仍缺有效锚点，现行核心会取消恢复资格，不能宣称该网站已完整可用。

还需在稳定可播放的原生视频上核验平台时间接口，以及控制栏自动隐藏后的持续可读性。这些是独立能力缺口；更多合成用例、构建通过和 Mac 已有结果都不能关闭。UIA 同步调用只能在返回后检查耗时，未成为可中断硬时限；相同全部观察值的换片与最终动作竞态仍属原有边界。

共用规则位于 [media-control-policy.md](../../media-control-policy.md)，合成用例位于 `tests/media-policy/cases.json`，Windows 已直接读取该文件执行。Mac 的具体核查点、保护本机改动的方法和验收要求见 [Mac 接续说明](../../macos-media-optimization-handoff.md)。[GitHub Issue #1](https://github.com/MrPPFruit/LookPause/issues/1)负责跟踪，已核对账号为MrPPFruit；规则与用例以版本化文件为准，不由Windows改写Mac实现或关闭Mac活动变更。

OpenSpec 6.1 是实施项；6.2 的真实网站效果、原有媒体矩阵与 S25 集中验收继续保持开放，不合 main。
