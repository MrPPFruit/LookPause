# 桌面媒体识别共用规则

2026-10-21，适用于 Windows 和 Mac 的后续优化。用户只在观影时开始使用 PausePal；开始表达观影意图，具体目标和后续暂停／恢复仍由桌面逐轮确认。协议及手机交互不变。

## 共用行为

1. 不要求网站给播放器容器起特定名称。名称可以提供媒体线索，不能成为唯一必需条件。
2. 目标属于当前实际前台顶层窗口及活动文档分支。同一播放器的嵌套文档是层级关系，不因存在多个文档就认定多个播放器。播放控制、seek与时间来源必须属于同一最近Document；文档祖先链用于关联上下文，不授予跨最近Document拼接证据的许可。兄弟框架不共用时间、进度或焦点证据。
3. 无名结构路径只接受完整的局部控件组：唯一明确播放控制、唯一时间进度、唯一音量及媒体动作；播放、时间进度、音量直接同组。可见后代有无关正文、导航、其他控件或文档时不授予该路径资格。音量只提供结构证据，不要求其滑块已展开；Windows仅对非Offscreen、启用的精确音量Slider允许空bounds，组、播放及进度仍须可见非空，不向音量提交动作。Mac允许已实测的等价包装层：seek直接属于外组，唯一播放控制与媒体动作属于一个直接控制栏，音量属于该栏或其一个局部子组；后代仍须封闭、同最近文档且没有Foreign或重复控制，不能任意压平页面。既有明确媒体名称路径属于另一路证据，不能把名称存在解释成任意控件均可被控制。
4. 只向已识别的具体控件提交固定动作。状态不明或多个目标时不猜测，不发全局盲切换，不增加扩展、站点脚本、网站名单或音频评分系统。
5. 开始不播放；明确播放时可单次暂停，必须确认同目标已暂停后才考虑恢复。恢复仍须有效且未结束的位置锚点、同目标、无接管、健康输入观察和及时采样。结构识别成功不是恢复资格。
6. 手动键盘、点击、滚轮及换目标只撤销本轮自动资格，观影保持。用户手动继续播放后再次离开可建立新轮；初始手动暂停不自动播放，停止／断线／重连不补播。UNKNOWN不凭空授予资格。
7. 时间数值必须有可解释单位和范围，缺失与结束分开。无单位滑块不自行当作秒，来源冲突或无法核验就取消恢复；不为看似测试通过而放宽。
8. 恢复成功后才最多尝试一次回退。回退能力独立，焦点不安全或时间能力不足时跳过，不能补发播放动作。控制播放按钮或进度条的能力，不自动证明它能保留全部媒体快捷键语义；需核验实际键盘承载面及异步焦点就绪，回退后空格／方向键仍应正常。网页一步不承诺固定五秒。

## 各平台的实现责任

Windows 将 UIA 节点映射到本地能力，保留 HWND、进程、文档链、局部组及控件身份；Mac 用 AX 节点和实际应用窗口上下文实现相同含义。UIA 的 Group 与 AX 的 AXGroup/角色描述并不完全等价，平台名称正则不能直接互相复制。

共用合成用例在 `tests/media-policy/cases.json`。其中结构用例验证无名组、跨分支拼接和多控制歧义；文档用例验证同分支、兄弟框架与外层文档变化。Windows 已将该文件接入自动回归；Mac于2026-10-26接入直接同组用例，并增加本平台封闭包装层与分离时间描述用例；最新代码与实测范围见[Mac报告](comet/reports/2026-10-26-mac-media-structure.md)，不将合成结果继承为完整产品验收。用例不包含真实网页、运行标识或私人媒体。

这组用例只描述辅助功能控件组和资格边界，不证明发现了实际 video 元素。控件、上下文、时长及暂停位置全部相同的原地换片，仍可能无法从现有观察面区分；观察到执行之间也有平台竞态。遇到证据缺失应准确报告，不以更多合成通过消除边界。

## 当前真实缺口

Windows 0.1.4已在真实Chrome原生视频上读齐ValuePattern当前时间与FullDescription总时长，并完成一次连续3轮及独立DOM只读核验。该路径有明确单位，不使用无单位RangeValue。字段映射及实测条件见[原生描述报告](https://github.com/MrPPFruit/LookPause/blob/1f5d597200a53025e5f2785cad9fe39da015d667/docs/comet/reports/2026-10-21-windows-native-description.md)。Mac已核对AXValueDescription的已播放时间与AXCustomContent的总时间；使用白名单安全解码，未把AX数值范围泛化为秒。Mac结果以本平台报告为准。

这仍不等于稳定支持：控制栏自动隐藏后，ControlView与RawView均缺少播放控件；另一补测出现暂停后时间描述变化，核心安全取消资格。0.1.5已取得用户网站本机pilot三轮恢复／回退及随后Space和方向键通过，见[回退报告](https://github.com/MrPPFruit/LookPause/blob/1f5d597200a53025e5f2785cad9fe39da015d667/docs/comet/reports/2026-10-21-windows-rewind-focus.md)；不继承为其他播放器、S25或完整保护矩阵通过。后续仍须研究状态与时间的一致性，不以固定等待、漂移容忍或忽略锚点掩盖失败。

暂停位置锚点在概念上不必以秒计量，5秒回退才依赖秒单位；但不能据此直接接受任意RangeValue。滑块可能使用默认0～100范围、百分比或直播可移动窗口，有限范围不证明完整媒体端点；百分比固定范围还会失去原有时长变化的换片线索。[WAI-ARIA slider规范](https://www.w3.org/TR/wai-aria-1.2/#slider)明确允许缺省范围。因此未来的无单位锚点方案须另行证明具体能力、媒体身份及结束边界，经审查后再实施；0.1.3没有采用这一泛化方案。

## 验收分层

各平台分别记录：静态检查、构建、共用合成用例、系统辅助功能实测、真实媒体连续暂停恢复、手机普通入口。至少包括无名原生控件、已有播放器回归、嵌套文档、兄弟框架时间／焦点、手动接管及后续新轮、初始暂停、结束和断线。Windows 结果不继承为 Mac 结果。

## 显式快捷键兼容模式例外

用户2026-10-31确认Mac沿用Windows的独立模式：默认关闭，下一START选择，开始零输入，离开／回看各一次Space，不验证媒体状态、不回退、不重试。它不承诺上文正常模式的暂停归属／初始手动暂停／结束识别；必须由用户主动选择并接受误切换风险。前台／焦点／输入／文档和停止／断线边界继续检查。Mac实现和未实测范围见[本轮记录](comet/reports/2026-10-31-mac-shortcut-mode.md)。
